
# 식품안전 데이터 기반 리스테리아 검출 예측 모델 개발

## 1. 과제 개요

- **과제 목표:** 식품안전 검사 데이터와 기후 데이터를 활용한 리스테리아 검출 예측 모델 개발
- **예측 대상:** 리스테리아 검출 여부 (Binary Classification)
  - 1: 검출
  - 0: 불검출
- **활용 데이터**
  - 식품안전 검사 데이터: 식품 유형, 품목, 수거일, 검사 결과 등
  - 공간 정보: 지역, 위치 및 관측소 정보
  - 기후 데이터: 수거일 기준 과거 100일간의 평균·최고·최저기온 등

---

# 2. 1단계: 식품안전 검사 데이터 기반 예측 모델 개발

## 2.1 데이터 탐색 및 전처리 (EDA & Preprocessing)

- 전체 테이블 및 데이터 구조 파악
- 테이블 간 JOIN 및 분석 데이터셋 구성
- 결측치, 중복 데이터 및 이상치 처리
- 검출·불검출 데이터 분포 분석
- 범주형 및 수치형 변수 전처리

## 2.2 피처 엔지니어링 (Feature Engineering)

- 식품 유형 및 품목별 파생변수 생성
- 지역 및 공간 정보 기반 파생변수 생성
- 수거일 및 검사일 기반 시간 변수 생성
- 식품 유형별·지역별 과거 검출률 생성
- 변수 간 상호작용 및 통계적 피처 생성
- 피처 중요도 분석 및 주요 변수 선정

## 2.3 머신러닝 모델 개발 및 최적화

- Logistic Regression, Random Forest, XGBoost 적용
- Stratified K-Fold 교차검증
- Grid Search, Random Search 및 Optuna를 활용한 하이퍼파라미터 최적화
- 모델별 예측 성능 비교 및 최적 모델 선정

---

# 3. 2단계: 기후 시계열 데이터 결합 및 예측 모델 개발

## 3.1 기후 데이터 전처리 및 결합

- 수거일 기준 과거 100일간 기후 데이터 확보
- 식품 검사 위치와 기상 관측소 간 공간적 매칭
- 평균기온, 최고기온, 최저기온 등 기후 변수 추출
- 결측치 및 이상치 처리
- 식품안전 데이터와 기후 데이터 결합

## 3.2 기후 데이터 피처 엔지니어링

- 과거 100일간 기후 시계열 데이터 구성
- 최근 7일, 14일, 30일, 60일, 100일 구간별 통계량 생성
- 평균, 표준편차, 최댓값, 최솟값 등 파생변수 생성
- 기온 변화량 및 변동성 변수 생성

## 3.3 머신러닝 및 하이브리드 딥러닝 모델 개발

- 식품안전 데이터와 기후 파생변수를 결합한 XGBoost 개발
- LSTM 또는 GRU 기반 시계열 모델 개발
- Transformer 기반 시계열 모델 개발
- 식품안전 정형 데이터와 기후 시계열 데이터를 결합한 Hybrid Deep Learning 모델 개발
- 교차검증 및 하이퍼파라미터 최적화

---

# 4. 모델 성능 평가 및 비교

- ROC-AUC, PR-AUC, Precision, Recall, F1-score 평가
- Confusion Matrix 분석
- 식품안전 데이터만 사용한 모델과 기후 데이터 결합 모델 비교
- XGBoost와 하이브리드 딥러닝 모델 성능 비교
- 기후 데이터 추가에 따른 예측 성능 개선 효과 분석
- 주요 피처 중요도 및 오분류 사례 분석

## 4.1 핵심 비교 실험

| 구분 | 입력 데이터 | 예측 모델 | 실험 목적 |
|:---:|---|---|---|
| 실험 1 | 식품안전·공간 정보 | XGBoost | 기본 예측 성능 확보 |
| 실험 2 | 식품안전·공간·기후 파생변수 | XGBoost | 기후 정보 추가 효과 분석 |
| 실험 3 | 식품안전 정형 데이터 + 기후 시계열 | Hybrid Deep Learning | 시계열 학습 효과 분석 |

# 6. 과제 수행 시 유의사항

- 검출 데이터 비율이 낮은 클래스 불균형 문제 고려
- PR-AUC와 Recall 중심의 성능 평가
- 과거 검출률 활용 시 데이터 누수 방지
- 교차검증과 별도로 시간 순서 기반 검증 고려
- 기후 데이터 추가가 리스테리아 검출 예측에 실질적으로 기여하는지 분석
